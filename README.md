# caseyhendler.com

Joke placeholder: a 1998 GeoCities-style "Official Unofficial Casey Hendler Fan Club".
Static site, no build step. Everything lives in `site/`.

Cloudflare Workers (static assets): `wrangler.jsonc` serves `site/`. Deploy command `npx wrangler deploy`, no build command.

- Movie: set `MOVIE_ID` (YouTube video id) near the bottom of `site/index.html`.
- Rickroll: "TOP SECRET blooper reel" button and the webring "Random" link.
- Easter eggs: Konami code, or click the spinning face 5 times.
- Webmaster: anonymous. Obviously.
